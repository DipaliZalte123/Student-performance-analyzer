# Student Performance Analyzer

My first Data Science project built with Python, Pandas & Matplotlib.

## Project Overview
This project analyzes student marks data to find insights:
- Calculates average, highest, lowest marks
- Finds which students need improvement
- Generates a visual performance graph

## Tech Stack
- Python 3
- Pandas
- Matplotlib
- Git & GitHub

## How to Run
pip install pandas matplotlib
python analysis.py

## Files
- data.csv - Student marks dataset
- analysis.py - Analysis code
- result_graph.png - Output graph
